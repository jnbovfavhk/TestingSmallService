# Проект UI-автотестов (nvanna.ru)

## 01. Выбор сайта
Сайт: https://nvanna.ru/
Ограничения: При частых запросах сайт возвращал HTTP 403 Forbidden (блокировка WAF). Для стабильной работы тестов и демонстрации использовалась смена IP / настройка `HEADLESS=false` и маскировка браузера. 

## 02. Авторизация
- **Применимый способ входа:** Логин (username) + Пароль. 
- **Исключения:** Вход по Email или телефону на сайте отсутствует, поэтому класс ошибки "неверный формат" адаптирован под проверку пустых полей и несуществующих логинов.
- Тест-кейсы актуализированы под модальное окно авторизации данного сайта.

## 03. Технологии
- Python 3.9+, Playwright, pytest, Allure.
- Архитектура: Page Object Model (папки `core`, `ui`, `autotest`).
- Защита данных: Пароли маскируются в логах и Allure через кастомный `logging.Filter`. Секреты хранятся в `.env`.

## 04. Как запустить
1. Установить зависимости: `pip install -r requirements.txt`
2. Установить браузеры: `playwright install chromium`
3. Заполнить `.env` своими данными.
4. Запустить тесты: `pytest`
5. Сгенерировать отчет: `allure serve reports/allure-results`
